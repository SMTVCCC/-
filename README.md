# AI时间计划自动转表格工具

这是一个纯前端实现的时间计划自动转表格工具，可以将文本格式的时间计划转换为结构化的表格和甘特图，并支持导出为Excel。

## 功能特点

- **多格式输入支持**：支持多种文本格式输入，如"周一 10:00-12:00 写代码"、"写代码 | 周一 | 10:00-12:00"等
- **AI辅助输入**：支持自然语言描述，AI自动转换为标准格式
- **自动解析**：智能解析输入文本，提取日期、时间和任务信息
- **冲突检测**：自动检测并标记时间冲突的任务
- **可视化表格**：生成美观的响应式表格
- **甘特图展示**：以甘特图形式直观展示时间安排
- **Excel导出**：一键导出为Excel文件
- **本地存储**：自动保存数据到浏览器本地存储
- **可编辑表格**：支持直接在表格中编辑任务内容

## 使用方法

1. 在文本框中输入时间计划，每行一个任务
   - 也可以点击AI辅助按钮，使用自然语言描述您的计划
2. 支持的输入格式示例：
   - `周一 10:00-12:00 写代码`
   - `写代码 | 周一 | 10:00-12:00`
   - `写代码 10:00-12:00 周一`
3. 点击"生成表格"按钮，系统会自动解析并生成表格和甘特图
4. 可以直接在表格中编辑任务名称
5. 点击"导出Excel"按钮可将表格导出为Excel文件
6. 点击"清除"按钮可清除所有内容

## AI辅助功能

AI辅助功能可以帮助您更自然地输入时间计划：

1. 点击输入框右上角的AI辅助按钮
2. 在弹出的对话框中，用自然语言描述您的时间计划
   - 例如："我想在周一上午10点到12点写代码，然后下午2点到4点开会"
3. 点击"转换"按钮，AI将自动解析您的描述并转换为标准格式
4. 点击"使用此结果"将转换后的内容填入主输入框

AI支持识别的表述方式：
- 星期：周一、周二、星期三等
- 时间：上午10点到12点、14:30-16:00等
- 任务：写代码、开会、学习等常见活动

## 输入格式说明

工具支持多种输入格式，主要包括：

1. **标准格式**：`星期 时间段 任务名称`
   例如：`周一 10:00-12:00 写代码`

2. **分隔符格式**：`任务名称 | 星期 | 时间段`
   例如：`写代码 | 周一 | 10:00-12:00`

3. **任务优先格式**：`任务名称 时间段 星期`
   例如：`写代码 10:00-12:00 周一`

4. **宽松格式**：只要包含时间段（格式为HH:MM-HH:MM）和可选的星期信息，系统会尝试解析

## 技术实现

- 纯前端实现，无需后端服务
- 使用原生JavaScript、HTML和CSS构建
- 使用ECharts库实现甘特图可视化
- 使用SheetJS库实现Excel导出功能
- 使用localStorage实现本地数据持久化
- 内置AI自然语言处理规则，支持中文时间表述转换
