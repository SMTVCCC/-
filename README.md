# -
时间计划助手
项目简介
时间计划助手是一个简洁高效的时间管理工具，帮助用户将自然语言描述的时间安排转换为结构化的时间表格和甘特图。无论是学习计划、工作安排还是日常生活规划，本工具都能帮助您轻松整理和可视化您的时间安排。
主要功能
自然语言输入：支持直接输入如"周一上午10点到12点写代码，下午2点到4点开会"等自然语言描述
AI智能识别：集成AI能力，自动将自然语言转换为标准格式的时间计划
多种输入格式：支持多种输入格式，包括"周一 10:00-12:00 写代码"、"写代码 | 周一 | 10:00-12:00"等
表格展示：将时间计划以表格形式清晰呈现，包含星期、任务、开始/结束时间、持续时间等信息
甘特图可视化：直观展示各任务的时间分布和持续时间
时间冲突检测：自动识别并标记时间冲突的任务
本地存储：自动保存您的时间计划，无需担心页面刷新导致数据丢失
Excel导出：支持将时间计划导出为Excel表格，方便分享和打印
使用方法
方法一：AI辅助输入
点击页面右上角的"AI辅助输入"按钮
在弹出的对话框中输入您的自然语言描述（如"周一上午10点到12点写代码，下午2点到4点开会"）
点击"转换"按钮，系统将自动分析您的输入并生成标准格式的时间计划
点击"使用此结果"将转换后的结果应用到主界面
方法二：结构化输入
切换到"添加任务"选项卡
在表单中选择星期、开始/结束时间并输入任务名称
点击"添加任务"按钮将任务添加到列表中
系统会自动生成表格和甘特图
